# Hr Dataset Report
This is a dashboard titled "HR Dataset Report." It displays a series of visualizations and key metrics related to an organization's human resources data.

## The dashboard includes:

- Count of MarriedID by Year: A bar chart showing the number of married employees hired each year.

- Count of EmpID by Sex: A donut chart illustrating the distribution of employees by gender (Male and Female).

- Count of EmpID by RecruitmentSource: A bar chart that breaks down the number of employees by their recruitment source (e.g., LinkedIn, Google Search, etc.).

- Count of EmpID by Position: A donut chart showing the distribution of employees across different job positions.
